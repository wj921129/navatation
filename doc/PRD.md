# 极简网页浏览器新标签页 — 产品需求文档 (PRD)

> 版本：v1.0 | 最后更新：2026-05-15 | 作者：全栈架构团队

---

## 一、产品概述

### 1.1 产品定位

「极简网页浏览器新标签页」是一款面向个人用户的浏览器起始页应用，旨在替代浏览器默认的新标签页，提供**极简、高效、可深度定制**的上网入口。用户打开新标签时，看到一个美观的搜索框与常用网址导航，无需多余操作即可开始浏览。

### 1.2 目标用户

| 用户类型 | 特征 | 核心诉求 |
|---------|------|---------|
| 普通网民 | 日常上网浏览 | 快速搜索、常用网站一键直达 |
| 效率追求者 | 关注生产力工具 | 高度自定义布局、快捷键操作 |
| 多设备用户 | PC + 移动端 | 跨设备数据同步 |

### 1.3 产品愿景

打造一个"打开即用、用完即走"的浏览器第一屏，让用户忘记默认新标签页的存在。

## 二、核心功能模块

### 2.1 搜索引擎模块

#### 2.1.1 功能描述
在搜索框内集成多搜索引擎切换能力，用户可一键切换搜索服务提供商。

#### 2.1.2 详细需求

| 编号 | 需求项 | 优先级 | 说明 |
|------|--------|--------|------|
| SE-01 | 多引擎切换 | P0 | 支持 Google、百度、必应，点击搜索框左侧图标弹出下拉选择 |
| SE-02 | 搜索执行 | P0 | 输入关键词后回车或点击搜索按钮，使用当前选中的搜索引擎跳转搜索 |
| SE-03 | 引擎记忆 | P1 | 记住用户上次选择的搜索引擎，下次打开自动使用 |
| SE-04 | 自定义引擎 | P2 | 允许用户添加自定义搜索引擎（名称+搜索URL模板） |

#### 2.1.3 交互流程
```
用户打开新标签 → 搜索框自动聚焦 → 左侧切换引擎(可选) → 输入关键词 → 回车/点击搜索 → 新标签页跳转搜索结果
```

### 2.2 快捷导航模块

#### 2.2.1 功能描述
以图标网格形式展示用户常用网站快捷方式，支持增删改查、拖拽排序与批量管理。

#### 2.2.2 详细需求

| 编号 | 需求项 | 优先级 | 说明 |
|------|--------|--------|------|
| NAV-01 | 默认快捷方式 | P0 | 系统预置 16 个常用网站（Google、YouTube、GitHub 等） |
| NAV-02 | 添加快捷方式 | P0 | 支持从推荐分类中选择或自定义添加（名称+URL+图标） |
| NAV-03 | 推荐分类 | P0 | 按类别展示推荐网站：看视频、AI工具、Web开发、购物、新闻资讯、游戏、音乐、办公效率 |
| NAV-04 | 批量添加 | P1 | 在添加对话框中可暂存多个快捷方式后一次性保存 |
| NAV-05 | 编辑快捷方式 | P0 | 进入编辑模式后点击图标可修改名称、URL、图标 |
| NAV-06 | 删除快捷方式 | P0 | 编辑模式下每个图标右上角显示删除按钮 |
| NAV-07 | 拖拽排序 | P1 | 编辑模式下支持拖拽调整图标位置 |
| NAV-08 | 自动抓取 Favicon | P1 | 输入网址后自动从目标网站抓取 favicon 作为图标 |
| NAV-09 | 自定义图标 | P1 | 支持上传本地图片或输入图片URL作为图标 |
| NAV-10 | 点击跳转 | P0 | 非编辑模式下点击图标在新标签页打开对应网址 |
| NAV-11 | 移动端适配 | P2 | 响应式网格布局，移动端自动调整列数 |

#### 2.2.3 推荐分类数据

| 分类 | 推荐网站 |
|------|---------|
| 看视频 | YouTube、Netflix、Bilibili、Twitch |
| AI工具 | ChatGPT、Claude、Midjourney、Gemini |
| Web开发 | GitHub、Stack Overflow、CodePen、MDN |
| 购物 | Amazon、淘宝、京东、eBay |
| 新闻资讯 | Reddit、Hacker News、Medium、BBC |
| 游戏 | Steam、Epic Games、IGN、GameSpot |
| 音乐 | Spotify、Apple Music、SoundCloud、YouTube Music |
| 办公效率 | Notion、Slack、Trello、Figma |

#### 2.2.4 编辑模式交互流程
```
点击编辑按钮 → 进入编辑模式(图标变为可点击状态) → 点击图标弹出编辑对话框 → 修改名称/URL/图标 → 保存
                                                                       → 点击X删除快捷键 → 确认删除
                              → 拖拽图标调整位置
                              → 点击保存(绿色按钮) → 退出编辑模式
                              → 点击取消 → 放弃所有修改 → 退出编辑模式
```

### 2.3 个性化设置模块

#### 2.3.1 功能描述
提供丰富的视觉自定义选项，让用户打造符合个人审美的起始页。

#### 2.3.2 详细需求

| 编号 | 需求项 | 优先级 | 说明 |
|------|--------|--------|------|
| SET-01 | 壁纸设置 | P0 | 支持三种方式：输入图片URL、本地上传图片、随机切换壁纸 |
| SET-02 | 搜索框尺寸 | P1 | 调节搜索框宽度(60%-100%)、高度(48-80px)、距顶部距离(100-300px) |
| SET-03 | 图标样式 | P1 | 调节图标大小(48-96px)、圆角(0-50%)、水平间距(16-64px)、垂直间距(24-72px) |
| SET-04 | 文字样式 | P1 | 调节图标下方文字大小(10-18px)、文字与图标间距(4-20px) |
| SET-05 | 整体布局 | P1 | 调节导航区域距搜索框距离(24-96px) |
| SET-06 | 主题模式 | P2 | 支持浅色/深色/跟随系统三种主题 |
| SET-07 | 设置同步 | P1 | 登录后将设置同步至云端，多设备共享 |

#### 2.3.3 设置面板交互
```
点击设置按钮 → 从右侧滑出设置面板 → 分区调整参数(实时预览) → 点击完成关闭
```

### 2.4 用户系统模块

#### 2.4.1 功能描述
提供用户注册、登录、登出能力，支撑个人数据云端同步。

#### 2.4.2 详细需求

| 编号 | 需求项 | 优先级 | 说明 |
|------|--------|--------|------|
| USR-01 | 用户注册 | P0 | 用户名 + 密码注册，用户名唯一性校验 |
| USR-02 | 用户登录 | P0 | 用户名 + 密码登录，返回 JWT Token |
| USR-03 | Token 刷新 | P1 | Access Token 过期后使用 Refresh Token 无感续期 |
| USR-04 | 用户登出 | P0 | 清除本地 Token，退出登录状态 |
| USR-05 | 登录状态持久 | P1 | 记住登录状态，关闭浏览器后无需重新登录 |
| USR-06 | 密码找回 | P2 | 通过注册邮箱重置密码 |
| USR-07 | 数据同步 | P1 | 登录后自动拉取云端配置和导航数据 |

#### 2.4.3 交互流程
```
点击用户图标 → 未登录时弹出登录对话框 → 输入用户名密码 → 登录成功(图标变为用户首字母+绿色在线标记)
                                                              → 登录失败提示错误信息
              → 已登录时弹出确认 → 确认登出 → 清除数据恢复默认
```

### 2.5 待办事项模块

#### 2.5.1 功能描述
在起始页中嵌入轻量级待办事项功能，帮助用户管理每日任务。

#### 2.5.2 详细需求

| 编号 | 需求项 | 优先级 | 说明 |
|------|--------|--------|------|
| TODO-01 | 创建待办 | P2 | 输入文字后回车快速创建待办项 |
| TODO-02 | 完成标记 | P2 | 点击复选框切换完成/未完成状态 |
| TODO-03 | 编辑待办 | P2 | 双击文字进入编辑模式 |
| TODO-04 | 删除待办 | P2 | 滑出删除按钮或右键删除 |
| TODO-05 | 待办排序 | P2 | 支持拖拽排序、已完成自动沉底 |
| TODO-06 | 待办同步 | P2 | 登录后同步至云端 |
| TODO-07 | 抽屉联动 | P1 | 待办清单组件位于右上角，点击空白处可开闭右侧详情管理抽屉 |

### 2.6 桌面小组件与工具栏 (Widgets & TopDock)

#### 2.6.1 功能描述
在首页提供顶部的快捷工具栏（TopDock）及可自由展示在桌面的独立小组件，提供时间管理、快捷设置与待办提醒等扩展能力。

#### 2.6.2 详细需求

| 编号 | 需求项 | 优先级 | 说明 |
|------|--------|--------|------|
| WGT-01 | TopDock 工具栏 | P1 | 位于首页顶部，集成多个常用小组件入口与控制开关，图标具备 macOS 风格阻尼鱼眼悬浮放大缩放动效 |
| WGT-02 | 时钟小组件 | P1 | 支持模拟、数字、传统（翻页）三种样式；支持在桌面上拖拽排版与边界限位；支持普通模式常驻显示及全局状态持久化 |
| WGT-03 | 专注番茄钟 | P2 | 集成在 TopDock 中，提供倒计时功能与呼吸脉冲微动画效果 |
| WGT-04 | 快捷视觉控制 | P1 | TopDock 提供一键皮肤切换（自适应 HSL 主题）与随机壁纸切换（带旋转动效）功能 |
| WGT-05 | 待办看板组件 | P1 | 在屏幕右上角悬浮展示未完结待办事项，支持主屏直接勾选销项；无未完结任务时自动完全隐藏 |
| WGT-06 | 小组件视效 | P2 | 统一采用高透毛玻璃（glass-widget）材质设计，根据深浅主题自动适配底色模糊度及文字清晰度 |

## 三、非功能性需求

| 编号 | 类别 | 要求 |
|------|------|------|
| NF-01 | 性能 | 新标签页打开到可交互时间 < 500ms |
| NF-02 | 性能 | API 接口响应时间 P99 < 200ms |
| NF-03 | 可用性 | 断网状态下仍可正常使用（本地缓存兜底） |
| NF-04 | 兼容性 | 支持 Chrome、Edge、Firefox 最新两个大版本 |
| NF-05 | 安全性 | 密码使用 BCrypt 加密存储，API 使用 HTTPS + JWT 鉴权 |
| NF-06 | 扩展性 | 后端采用分层架构，支持水平扩展 |
