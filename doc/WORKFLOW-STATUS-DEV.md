### 2026-06-09 任务日志：基于 ReactDnD 重构推荐网址，实现完美换行拖拽
- **需求背景**：用户要求优化推荐网址弹窗的拖动体验，原有第三方组件在网格换行时会出现挤压和剧烈闪动，严重影响功能使用。
- **实施细节**：将预览模式下的网址图标拖动排序重构为基于 `react-dnd` (`useDrag` / `useDrop`) 的轻量级高阶事件驱动实现。在拖动时直接通过 hover 回调修改底层数组顺序触发 React 的 state 变更，完全将换行计算工作移交给浏览器原生的 Flexbox 排版引擎。实现了图标在拖拽过程中的完美自适应换行，且按钮常显、绝无重叠，彻底解决了一维拖拽库在网格下的硬伤。
- **状态**：已完成并推送到 dev 分支。

### 2026-06-08 任务日志：彻底物理表隔离管理员（Root）数据
- **需求背景**：用户要求管理员账户登录时，与普通用户数据进行物理表级别的彻底隔离。
- **实施细节**：
  - 数据库层：执行 DDL 新建了 5 张 `navatation_root_*` 前缀的数据表（涵盖配置、分类、快捷方式、组件、待办事项）。
  - 后端实体与持久化层：新建 `RootConfig`、`RootCategory` 等 5 个 Entity 和对应的 Mapper。
  - 业务层：重构所有相关 Service 层逻辑，检测如果角色为 `ADMIN`，则直接拦截并切流至 `Root*Mapper` 操作对应的独立表，实现彻底的物理级别权限数据隔离。
- **状态**：已完成并推送到 dev 分支。

### 2026-06-08 任务日志：推荐网址批量管理与后端规范重构及实体包分类
- **需求背景**：为提升管理员批量维护推荐网站的效率，设计并实现推荐网址以分类为维度的“批量管理模式”；并完成全栈的规范化大面积重构。
- **实施细节**：
  - **前端功能开发**：在“推荐”页签新增卡片式界面的“批量编辑模式”，实现对分类内书签的增加、删除、一键批量保存。并且集成了基于后端竞速的 favicon 图标嗅探功能和自定义多图备选逻辑。
  - **后端并发重构**：新增批量保存接口并增加 `@Valid` 级联校验；将循环写数据库的单条逻辑，利用 MyBatis-Plus 静态工具 `Db` 重构为批量聚合写入 (`Db.saveBatch` / `Db.updateBatchById`)，并针对并发网络请求实现了防 OOM 的线程池隔离策略。
  - **包结构优化**：将平铺的 Entity 实体类按业务重构分为 `user`、`nav`、`recommend`、`root` 四个子包。
- **状态**：已完成并推送到 dev 分支。

### 2026-05-25 任务日志：业务 ID 逻辑 UUID 化、自增 row_id 引入与超长内容校验优化
- **需求背景**：应对分布式安全需要，防止业务数据被顺序遍历，需要将显式主键 UUID 化。
- **实施细节**：
  - 对 7 张表的物理主键进行升级，引入带业务前缀的 VARCHAR(64) UUID（例如：U_123456 / TD_98765）；同时补充了底层自增 `row_id` 进行页分裂性能优化。
  - 重构 Controller 与 Service，对实体请求对象增加 `@Size(max=512)` 参数校验机制，提升框架的整体防错健壮性。
- **状态**：已完成。
