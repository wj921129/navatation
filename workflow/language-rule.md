# 全局使用中文规则

为保证项目代码易读性、维护性与规范性，多 Agent 在开发中必须强制遵守以下语言规则：

1. **代码注释**：所有代码中的文件头注释、类注释、方法 Javadoc/JSDoc 注释、行内关键逻辑描述以及常量注释等，必须全部使用**中文**。
2. **Git 提交信息**：在使用 Git 提交代码（如 `git commit -m`）或调用代码推送脚本时，提交消息（Commit Message）必须强制使用**中文**，清晰描述本次提交改动的具体功能或修复的 Bug。
3. **接口异常与提示**：对用户展现的交互提示文字、接口异常处理信息（Exception Messages）等，应以用户体验为首，统一使用**中文**友好提示。
4. **项目文档与说明**：所有的技术方案、接口文档、架构设计、Bug 汇报以及与用户在终端的沟通交流过程，必须无条件完全使用**中文**。
